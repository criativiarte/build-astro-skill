Este é um post simples para mostrar a estrutura básica dos posts.

Use este arquivo como referência para os campos do template. Depois de configurar o CMS, você pode criar e editar posts em `/admin/`, selecionando autores e tags cadastrados no painel.

## O que este post demonstra

- Título com até 100 caracteres e descrição com até 160.
- Status Publicado ou Rascunho para controlar a exibição no site.
- Autor opcional e tags com páginas próprias.
- Capa local opcional, processada pelo Astro.
- Conteúdo em Markdown na coleção `posts`.

As alterações salvas pelo CMS ficam no GitHub e aparecem no site após o build e deploy. Substitua este conteúdo pelo primeiro post do seu projeto.
