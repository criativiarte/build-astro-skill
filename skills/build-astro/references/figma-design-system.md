# Figma e design system

## Obter o design com acesso autorizado

1. Quando houver link do Figma, use o MCP remoto oficial. No Codex desktop, prefira o plugin oficial Figma já conectado. No CLI ou em clientes que não ofereçam o plugin, use o servidor remoto OAuth; o comando de cadastro no Codex CLI é `codex mcp add figma --url https://mcp.figma.com/mcp`. Use uma conexão já autorizada e encaminhe a autenticação ao desenvolvedor se for necessária. Quando o pedido indicar capturas ou arquivos como referência, trabalhe com o material autorizado e registre o nível de fidelidade. [Configuração oficial para Codex](https://help.figma.com/hc/en-us/articles/39888629089175-Codex-and-Figma-Set-up-the-MCP-server)
2. Para implementação com contexto estruturado, carregue a skill oficial `figma-design-to-code` antes de chamar `get_design_context`. Siga a versão instalada, inclusive a identificação em `skillNames`, a solicitação inicial do screenshot e o tratamento de respostas esparsas. Se faltar a captura, obtenha-a pelo fluxo oficial antes de editar. Faça leituras do arquivo. Operações de escrita no canvas exigem um pedido específico.
3. Para links de frame, use o `node-id` do alvo. Para links de arquivo, use metadados para localizar os frames principais antes de pedir contexto de implementação. Em resposta esparsa, use a captura e a hierarquia para fazer uma leitura agrupada dos nós visíveis e relevantes. Use variáveis e leituras adicionais para preencher lacunas confirmadas. Reaproveite as respostas já obtidas e salve os assets autorizados no projeto antes que os links temporários expirem. [Ferramentas oficiais do Figma MCP](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/)
4. Proteja a cota de leitura. Na revisão de novembro de 2026, o Figma documentava até 20 leituras MCP por mês para Starter e assentos View/Collab, além de limites por minuto e permissões do arquivo. Consulte o limite atual se necessário. O MCP desktop requer assento Dev ou Full em plano elegível. [Limites e acesso](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/)
5. Se o MCP estiver indisponível ou a cota acabar, pare as chamadas e avalie o material de referência já fornecido. Consulte a visualização autorizada no modo Design para completar lacunas, quando necessário e permitido. Use capturas, tokens e assets como evidência para um escopo visual aproximado, sem atribuir a eles a fidelidade de contexto estruturado. Se o fluxo acionado exigir esse contexto ou faltar material essencial, peça acesso ao frame, assets ou confirmação do escopo aproximado. Avance nas partes independentes enquanto houver trabalho útil. [Inspeção no Figma](https://help.figma.com/hc/en-us/articles/22012921621015-Guide-to-inspecting)

## Traduzir para o projeto

- Relacione frames às rotas e seções. Mapeie variáveis e estilos aos tokens de cor, fonte, espaçamento e componentes já existentes. Reutilize os mapeamentos Code Connect quando compatíveis. Trate snippets gerados pelo Figma como contexto e converta-os para Astro e para as convenções do projeto.
- Recrie o layout com fluxo, grid e flexbox. Use frames como evidência e derive comportamento fluido entre eles. Preserve tipografia, ritmo, hierarquia e proporções. Use capturas como referência de comparação e mantenha o conteúdo em HTML. Confirme cada asset estático relevante em seu arquivo local, componente e posição renderizada.
- Proteja estados de foco, contraste, semântica, áreas de interação e movimento reduzido mesmo quando o frame não os explicitar. Trate estados vazios, erro e textos longos de acordo com os dados e contratos reais.
- Componha seções com a grade do projeto e preserve a API do `Container` quando existir. Use o ponto de composição para variações exigidas pelo design. Em um site novo com Tailwind v4, sem grade existente nem largura definida, use `mx-auto w-17/20 max-w-7xl`.
